# Guga Abuser Blocker · 0.1.0

[简体中文](README.zh-CN.md) · [English](README.en.md)

Guga コミュニティ向けの Chrome / Edge 拡張機能です。アカウントリストの取り込みと確認、共有リストの購読、X 上の投稿の非表示、任意の X ブロックを行います。日本語・英語・中国語に対応しています。初期状態にアカウントリストは含まれず、自動ブロックはオフです。


## リポジトリと購読

[v0.1.0 プレビューをダウンロード](https://github.com/ZOC698/guga-abuser-blocker/releases/tag/v0.1.0) · [公開リスト](lists/guga-blocklist.json) · [確認手順](CONTRIBUTING.md)

**公開リストは現在 0 件で、ブロック効果はありません。最初の確認済みリストを準備中です。** 個人の確認待ち候補は公開しません。数値 ID は後から追加でき、現在のユーザー名で運用できます。

拡張機能の購読画面に次の固定 URL を貼り付けてください。

```text
https://raw.githubusercontent.com/ZOC698/guga-abuser-blocker/main/lists/guga-blocklist.json
```


## インストール

1. リリースの ZIP を展開し、展開先のフォルダーを保管します。
2. Chrome で `chrome://extensions`、Edge で `edge://extensions` を開きます。
3. 「デベロッパーモード」を有効にし、「パッケージ化されていない拡張機能を読み込む」で `manifest.json` が直接入っている **extension** フォルダーを選びます。
4. 開いている X のタブを再読み込みします。拡張機能のアイコンから管理画面を開き、サイドバーで日本語を選べます。

Chromium 120 以降が必要です。ブラウザーストアには未公開のローカル読み込み版です。更新時はファイルを置き換え、拡張機能管理画面で再読み込みした後、X も再読み込みしてください。

## 取り込みと確認

「アカウント一覧」で TXT・CSV・JSON をプレビューして取り込むか、ユーザー名を貼り付けます。**ファイルやページから取り込んだアカウントはすべて確認待ち**になります。ファイルに `approved` と書かれていても自動承認されません。内容を確認した Guga 関連のアカウントを選び、理由や根拠を追加して承認してください。個人のブロック一覧に含まれる無関係なアカウントを共有しないようにします。

ページから取り込む場合は [X のブロックしたアカウント](https://x.com/settings/blocked/all)を開き、拡張機能で収集を開始し、最後に収集結果を取り込みます。自動スクロールで取得できるのは X が実際に表示したアカウントだけです。収集が止まっても全件取得の保証にはなりません。新しい収集では対象アカウントに紐づく新しいスナップショットを作成します。

## 購読とブロック

1. 「購読」で信頼する管理者の公開 GitHub Raw JSON URL を追加し、`raw.githubusercontent.com` へのアクセスを許可します。GitHub アカウント、PAT、X API キーは不要です。
2. 購読はそのリストの各項目を信頼する操作です。個別のローカル承認なしで適用されます。手動更新のほか、ブラウザーが動作し、端末が起動している間は約 6 時間ごとに更新を確認します。
3. ログイン済みの X タブを開き、「設定とヘルプ」から使用する X アカウントを接続します。
4. 自動 X ブロックをオンにすると、既存および新しく追加された有効な項目がキューに入ります。操作履歴画面から手動で開始することもできます。間隔は最短 30 秒、最大 300 秒です。ブラウザーと専用 X タブを開いたままにしてください。

投稿の非表示と X 自体のブロックは別の機能です。許可リストは購読より優先され、今後の非表示とブロックを除外します。購読・項目の削除や許可リストへの追加で、**すでに実行した X ブロックは解除されません**。解除は X で行ってください。キューは一時停止できますが、X に送信済みの操作は取り消せません。

## リストを共有する

一覧から共有用 JSON を書き出します。`guga-blocklist.json` には承認済みのローカル項目だけが入り、許可リストと購読元の項目は除外されます。内容を確認し、公開 GitHub リポジトリに手動でアップロードして、Raw URL を共有します。

```text
https://raw.githubusercontent.com/ZOC698/guga-abuser-blocker/main/lists/guga-blocklist.json
```

更新時も同じファイルパスを使用します。拡張機能がファイルを自動アップロードしたり、GitHub に書き込んだりすることはありません。**個人の元データ、非公開バックアップ、個人の完全なブロック一覧を配布パッケージや公開リポジトリに含めないでください。** 記載された理由や行為についてはリスト管理者が確認するものであり、拡張機能が事実認定するものではありません。

## 現在の制限

- 0.1.0 はローカルの模擬ページとテストで検証しています。ログイン済みの実際の X での一連のブロック操作は未検証です。画面変更、ログインアカウントの変更、対象の不明確さ、結果を確認できない場合には停止します。操作履歴と X の状態を確認してから再試行してください。
- 現在のユーザー名で対象を開きます。数値 ID が指定されている場合、X ブロック前に固定した ID を照合し、不一致や確認不能なら停止します。改名を自動追跡する機能はありません。ユーザー名だけでは再利用後の同一性を保証できず、投稿の非表示はユーザー名で照合します。
- 鳥盾の数値 ID だけのファイルには、取り込み前に現在のユーザー名を補う必要があります。[データ形式](DATA_FORMAT.md)を参照してください。
- 非公開 JSON と CSV の書き出し対象はローカル項目です。設定・購読・履歴の完全なバックアップではありません。再取り込み後は再確認が必要です。アンインストールで拡張機能内の保存データは消えますが、X ブロックは残ります。

Twitter 鳥盾の共有リスト方式を参考にしています。作者の[ストアページ](https://chromewebstore.google.com/detail/twitter-bird-shield/igapbfjkbkmjcmgjmgfcegamhkfppdmg)には GitHub 共有の説明があり、[データリポジトリ](https://github.com/free-spirit-dev/bird-shield-blocking)には分類別の数値 ID ファイルがあります。本拡張機能は独立した実装で、ソースコード・アイコン・リストを複製しておらず、完全な相互互換性も主張しません。
