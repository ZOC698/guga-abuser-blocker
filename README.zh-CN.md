# Guga Abuser Blocker · 0.1.2 预览版

[English](README.en.md) · [日本語](README.ja.md)

面向 Guga 同好的 Chrome / Edge 扩展，支持中文、日文、英文。订阅维护者发布的公开名单，保留自己的例外，并按设置在已登录的 X 账号上自动拉黑；也支持本地导入和私人备份。首次安装时自动拉黑关闭。

**订阅只有读取功能。扩展不能向公共仓库上传、发布或提交候选条目，也不接收 GitHub PAT。** 本地导入、批准和编辑始终留在当前浏览器；公共名单由维护者独立发布。

## 安装与订阅

1. 解压扩展包并保留文件夹。打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的 **extension** 文件夹，然后刷新已有 X 标签页。
3. 点击工具栏扩展图标，即可在弹窗里使用完整的概览、名单、订阅、记录与设置，无需另开管理标签页。在「名单订阅」添加公开 GitHub Raw JSON 链接，并授予 `raw.githubusercontent.com` 读取权限。无需 GitHub 账号、PAT 或 X API 密钥。

连接时优先读取当前 X 标签页，只在当前窗口内选择账号。识别使用 X 自己的个人主页导航和账号头像标识，支持账号按钮不显示用户名的布局。扩展更新后若当前页面尚未加载脚本，连接操作会在该 X 页补载本地脚本。弹窗关闭后，输入草稿和导航位置会保留到本次浏览器会话结束；它们不会上传。
4. 打开已登录的 X 标签页，在「设置与帮助」连接账号。这是选定队列可以操作的账号，不是开发者 OAuth 授权。
5. 开启「自动 X 拉黑」。刷新后符合条件的条目会进入队列；保持浏览器和专用 X 标签页打开。操作间隔至少 30 秒，可调至 300 秒。

需要 Chromium 120 或更新版本。这是开发者加载预览版，尚未完成 Chrome / Edge 在真实 X 上的跨环境验证。可手动刷新；浏览器可运行时约每 6 小时检查订阅，休眠、关机和后台调度可能推迟执行。更新文件后重新加载扩展，并刷新 X。

## 你的私人账号库

在「账号库」预览并导入 TXT、CSV、JSON，或粘贴用户名。新增条目一律待审核，不信任导入文件的批准标志。审核后批准，仅用于你自己的隐藏和拉黑，不会发布。

点击本地条目的「编辑」可补充或修正数字用户 ID。输入 1–25 位数字并按字符串保存；修正已有 ID 后会回到待审核；补充缺失 ID 保留审核状态，已有 ID 不允许清空。仍需提供当前用户名。导入结果分别显示新增、更新和重复数量；合并规则见[数据格式](DATA_FORMAT.md)。

采集现有屏蔽名单时，先打开 [X Blocked accounts](https://x.com/settings/blocked/all)，在账号库启动采集，最后导入结果。只收集 X 实际渲染的账号；显示空闲不代表全量导出完成。

私人 JSON / CSV 仅备份本地条目，不包含全部设置、订阅与日志。重新导入的新增条目需要审核。私人备份应保留在公共仓库和发行包之外。

## 拉黑方式与当前边界

当前主执行路径仍操作 X 页面的按钮（DOM）。提交后重新加载目标主页，再核对登录账号、目标身份和已拉黑按钮。这是页面读回核对，不是独立的服务端 API 确认。内部接口适配器正在单独验证，尚未作为默认队列执行方式；X 页面变动仍可能中断流程。

提供数字 ID 时会在操作前核对，不一致或无法核对时停止。用户名改名或被重新分配后，仅凭用户名不能保证身份；内容隐藏仍按用户名匹配。鸟盾的纯数字 ID 文件需先补充当前用户名映射。

白名单例外优先于未来的隐藏和拉黑。移除订阅、移除条目或添加例外不会解除已有 X 拉黑，需自行在 X 解除。队列可以暂停，但已经提交的操作不能撤回；对不确定结果，应查看操作记录与 X 后再重试。

真实 X 上跨浏览器、语言和账号状态的完整认证流程仍未完成验证。模拟页面测试只能证明覆盖到的模拟场景，详见[验证记录](VERIFICATION.md)。
