# Guga Abuser Blocker · 0.2.0 预览版

[English](README.en.md) · [日本語](README.ja.md)

面向 Guga 同好的 Chrome / Edge 扩展，帮助减少看到维护名单内账号的内容，支持中文、日文、英文。覆盖范围取决于维护名单，未收录账号仍可能出现。订阅维护者发布的公开名单，保留自己的例外，并按设置在已登录的 X 账号上自动拉黑；也支持本地导入和私人备份。首次安装时自动拉黑关闭。

**订阅只有读取功能。扩展不能向公共仓库上传、发布或提交候选条目，也不接收 GitHub PAT。** 本地导入、批准和编辑始终留在当前浏览器；公共名单由维护者独立发布。

## 安装与订阅

1. 解压扩展包并保留文件夹。打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，加载直接包含 `manifest.json` 的 **extension** 文件夹。
2. 在当前浏览器配置中登录 X。点击工具栏扩展图标，即可在弹窗内使用概览、名单、订阅、记录与设置。
3. 在「名单订阅」添加上方公开名单地址，并授予 `raw.githubusercontent.com` 读取权限。订阅者无需终端、Codex、GitHub 账号、PAT 或 X 开发者 API 密钥。
4. 点击「连接 X 会话」，后台核对当前登录会话并绑定数字账号 ID。**从 0.1.x 升级后，需要重新连接，再开启拉黑。** 这不是开发者 OAuth 授权。
5. 开启「自动 X 拉黑」。已审核且有数字 ID 的条目进入后台队列；保持浏览器运行，无需专用的 X 用户主页标签页。请求间隔至少 30 秒，可调到 300 秒。

需要保持 X 登录状态。账号或会话变化、认证失败后需要重新连接。限流、请求预算或网络重试可能触发持久冷却，弹窗会显示等待期限；关闭弹窗或重启后台不能绕过冷却。

需要 Chromium 120 或更新版本。这是开发者加载预览版，尚未完成 Chrome / Edge 在真实 X 上的跨环境验证。可手动刷新订阅；浏览器可运行时约每 6 小时检查更新，休眠、关机和调度可能推迟执行。更新文件后重新加载扩展，并刷新 X 标签页以更新内容隐藏。

## 你的私人账号库

在「账号库」预览并导入 TXT、CSV、JSON，或粘贴用户名。新增条目一律待审核，不信任导入文件的批准标志。审核后批准，仅用于你自己的隐藏和拉黑，不会发布。

点击本地条目的「编辑」可补充或修正数字用户 ID。输入 1–25 位数字并按字符串保存；修正已有 ID 后会回到待审核；补充缺失 ID 保留审核状态，已有 ID 不允许清空。仍需提供当前用户名。导入结果分别显示新增、更新和重复数量；合并规则见[数据格式](DATA_FORMAT.md)。

采集现有屏蔽名单时，先打开 [X Blocked accounts](https://x.com/settings/blocked/all)，在账号库启动采集，最后导入结果。只收集 X 实际渲染的账号；显示空闲不代表全量导出完成。

私人 JSON / CSV 仅备份本地条目，不包含全部设置、订阅与日志。重新导入的新增条目需要审核。私人备份应保留在公共仓库和发行包之外。

## 拉黑方式与当前边界

0.2.0 使用浏览器已登录的会话，在后台请求 X 网页内部接口，并通过接口读回拉黑关系后才记录成功。队列不再点击用户主页菜单。网页内部接口与公开文档中的开发者 OAuth API 不同，也可能随 X 更新变化。

每次原生拉黑都必须有现成的目标数字 ID。只有用户名的已审核条目显示「待补数字 ID」，不会发送拉黑请求。可编辑本地条目补齐，订阅条目则等待名单维护者更新。队列不会自动按用户名查询 ID 后拉黑。执行前后核对数字目标身份和所连接的数字账号身份；内容隐藏仍按用户名匹配。

弹窗表单和导航草稿保留在当前浏览器会话中。连接结果、队列状态和冷却独立持久保存，关闭弹窗不会丢掉操作结果。

白名单例外优先于未来的隐藏和拉黑。移除订阅、移除条目或添加例外不会解除已有 X 拉黑，需自行在 X 解除。队列可以暂停，但已经提交的操作不能撤回；对不确定结果，应查看操作记录与 X 后再重试。

真实 X 上跨浏览器、语言和账号状态的完整认证流程仍未完成验证。模拟页面测试只能证明覆盖到的模拟场景，详见[验证记录](VERIFICATION.md)。
