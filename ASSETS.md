# Guga artwork

The classic character icon reuses the maintainer's existing GuguPet application artwork. It depicts Guga in the penguin hood, with dark hair, a blue hair clip and a collar. It is not a newly generated replacement character.

The 16, 32, 48 and 128 pixel PNG files in `extension/icons` are extracted directly from the corresponding PNG frames in the original `Assets/gugu.ico`, without redrawing or re-encoding them. The popup and management page use this same artwork.
